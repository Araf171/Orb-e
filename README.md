## Description

A 2D arcade-inspired game featuring three different modes: shooting projectiles at a target, evading enemies in a confined arena, and a sidescrolling auto-runner with unique collision-based mechanics

## Project Information

- **Language:** C
- **Graphics Library:** raylib
- **Development Environment:** Visual Studio Code
- **Project Setup:** [Raylib-Quickstart](https://github.com/raylib-extras/raylib-quickstart)

## Building and Running

The project was developed using the Raylib-Quickstart setup for Visual Studio Code.

To build and run the project:

1. Clone the repository in Visual Studio Code.
2. Ensure that the C compiler/toolchain is installed and available to VS Code.
3. Press F5 to build and run the project.

The executable can be found in the Orb-e\bin\Debug directory after building and running. If running this executable standalone, include the "assets" folder in the same directory as it.
